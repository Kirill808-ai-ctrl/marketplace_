Эта папка зарезервирована для локальных изображений товаров.

Сейчас все изображения подключены по внешним ссылкам (https://picsum.photos/seed/...)
как реалистичные заглушки, чтобы проект сразу выглядел как полноценный маркетплейс
и открывался без дополнительной настройки. Для их отображения нужен доступ в интернет.

Чтобы использовать собственные фотографии товаров:
1. Положите файлы сюда, в папку images/ (например: images/hoodie-1.jpg).
2. В файле js/products.js замените значение поля "image" (и элементы массива "images")
   у нужного товара на относительный путь, например: "images/hoodie-1.jpg".
